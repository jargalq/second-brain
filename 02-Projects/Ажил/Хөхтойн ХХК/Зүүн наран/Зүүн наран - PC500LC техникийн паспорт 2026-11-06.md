# Зүүн наран: Komatsu PC500LC-10R SE техникийн паспорт

## For future agent

Дайрганы (андезит) Зүүн нарангийн уурхайд Komatsu PC500LC-10R SE (сум 6670 / шанага 2900 мм, хувин 3.7 м³)-ийг 5 м-ийн 3 шатаар хормойгоос ухаж, HOWO 25 тн-д ачих техникийн паспорт. Төлөв — **санал**: батлагдсан паспорт R380LC-9-ээр хэвээр ([[Зүүн наран - ухаж ачих ажлын паспорт 2026-11-03]]). Техникийн тоо Komatsu-ийн каталогоос, ⚠-тэй мөр таамаг.

## 2. Ажлын схем

Шатны өндөр **5 м**, 60°-ын налуутай. Ухалтыг 3 × 5 м шатаар (+ ёроолын 2.3 м шат) хийнэ ([[ТЭЗҮ 04 - Ил уурхайн төлөвлөлт]]).

Экскаватор тэсэлсэн андезитын бутархайн **хормой дээр**, HOWO-той нэг түвшинд зогсоно. Бутархайг нүүрээс нь дээш ухаж, хажуу тийш эргэж машинд ачна. Шат бүрийг дуусгаад налуу замаар дараагийн шат руу шилжинэ (Mugi-ийн шийдвэр → [[2026-11-06 - PC500LC SE 3.7 м³-ээр хормойгоос ухаж ачина]]).

| Шалгуур | Шаардлага | PC500LC SE | Дүгнэлт |
|---|---|---|---|
| Ухах өндөр | шат 5 м + бутархайн овоо | 10.2 м | ✅ |
| Асгах өндөр | HOWO-гийн өндөр ≈ 3.45 м ⚠ (дилер) | 6.75 м (нөөц ≈ 3.3 м) | ✅ |
| Босоо ханаар ухах | хормойгоос ажиллахад шаардлагагүй | 2.7 м | — |
| 15 м-ийг нэг байрлалаас | — | ухах гүн 7.15 м | ❌ шат бүрээр |

## 4. Ачилт ба бүтээл

Чулуулаг: андезит, цул нягт 2.69 т/м³; дүүргэлт 0.8, сэвсгэршил 1.5 — батлагдсан паспорттой ижил.

| Үзүүлэлт | Утга |
|---|---|
| Нэг хувинд | 3.7 × 0.8 / 1.5 = **1.97 м³ цул ≈ 5.3 т** |
| Нэг машинд (HOWO 25 т) | 4 хувин = 21.2 т · 5 хувин = 26.5 т (+6 % ⚠ хэт ачаалал) → **5-р хувинг дутуу дүүргэж ≈ 25 т** |
| Сэвсгэр эзэлхүүн (5 хувин) | ≈ 14.8 м³ — тэвшинд (≈ 19 м³ ⚠ дилер) багтана ✅ |
| Цикл | 25 с ⚠ (R380LC-9-тэй ижил гэж авав; каталогт байхгүй) |
| Нэг машин ачих хугацаа | ≈ 2.1 мин (R380LC-9: 4.2 мин) |
| Бүтээл: техникийн / ашиглалтын (kи 0.75) | 284 / 213 м³/цаг цул ⚠ |
| Бүтээл: ээлжид / жилд (2 ээлж, 184 хоног) | ≈ 1 815 м³ / ≈ 668 000 м³ ⚠ |
| Жилийн хэрэгцээ 175 000 м³ | ≈ 820 цаг → **ачаалал ≈ 26 %** |

> ⚠️ Ачаалал 26 % нь PC500LC энэ уурхайн хэмжээнд хэт том байж болохыг харуулна (R380LC-9: 51 %). Сонголтыг эцэслэхээс өмнө Mugi-тэй тулгах.
