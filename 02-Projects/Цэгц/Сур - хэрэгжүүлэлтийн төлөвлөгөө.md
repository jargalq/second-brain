# Сур MVP: хэрэгжүүлэлтийн төлөвлөгөө

> **Агент ажилтанд:** заавал хэрэглэх дэд skill нь superpowers:subagent-driven-development (санал болгож буй) эсвэл superpowers:executing-plans. Даалгавар бүрийг дарааллаар нь хийнэ. Алхмууд нь `- [ ]` checkbox хэлбэртэй.

**Зорилго:** арьс шир боловсруулах үйлдвэрийн түүхий эдийн хүлээн авалт → үйлдвэрлэлийн шат → борлуулалтыг бүртгэдэг, тайлан гаргадаг, Холбоонд нэгдсэн самбар өгдөг олон байгууллагын вэб апп (Сур) хийнэ.

**Архитектур:** Next.js (App Router) сервер компонент ба server action → Supabase Postgres. Байгууллагыг row-level security (RLS)-ээр тусгаарлана. Бизнесийн бүх тооцоо (нөөц, гүн боловсруулалт, урамшуулал, импорт) `src/domain/` дотор цэвэр TypeScript функц байх тул өгөгдлийн сангүйгээр тестлэгдэнэ. Холбоо түүхий хүснэгтийг шууд харахгүй, зөвхөн `security definer` функцээр нэгтгэсэн тоог авна.

**Технологи:** Next.js 15, TypeScript, Supabase (Postgres 15, Auth, CLI), Vitest, SheetJS (`xlsx`), Tailwind CSS, Vercel.

**Spec:** [[Сур - MVP дизайн ба бизнес төлөвлөгөө]]

## Нийтлэг хязгаарлалт

- Интерфейсийн бүх бичвэр монголоор (кирилл). Код, хүснэгт, функцийн нэр англиар.
- Програм дотор AI, гадны AI API байхгүй.
- Мөнгө: `numeric(14,2)`, төгрөгөөр. Дэлгэцэнд `1 234 567₮` хэлбэрээр харуулна. Огноог `2026.11.05` хэлбэрээр харуулна.
- Байгууллага бүрийн өгөгдлийг RLS-ээр тусгаарлана. Холбоо үнэ, төлөөлөгч, малчны мэдээллийг хэзээ ч харахгүй.
- Шатны дараалал: `raw` (түүхий) → `salted` (давсалгаа) → `wet_blue` (вет-блю) → `crust` (краст) → `finished` (савхи/бэлэн).
- Supabase-ийн бүс: Сингапур (`ap-southeast-1`).
- Падааны дугаар давхардвал **хориглохгүй, анхааруулна** (spec).
- Урамшууллын хувь хэмжээг тохируулж болдог байна. Анхдагч утга нь 2013 оных: бог мал 3 000₮, бод мал 15 000₮.
- Гүн боловсруулалтын хувийн жинг тохируулж болдог байна. Холбооны албан ёсны аргачлал ирэхээр солино (доорх Даалгавар 8-ыг үз).

## Хянах гол эрсдэлүүд

1. **Падааны дугаарын бичлэгийн ялгаа.** `А-123`, `а-123 `, мөн латин `A-123` (кирилл "А"-тай адилхан харагддаг) гурвыг ижил дугаар гэж үзэж анхааруулах ёстой → Даалгавар 4, `normalizePadaanNo`.
2. **Шатанд байгаагаас илүүг шилжүүлэх эсвэл зарах.** Татгалзаж, хэдэн ширхэг байгааг монголоор хэлэх ёстой → Даалгавар 5, 6.
3. **Excel-ийн огноо, тоо монгол хэлбэртэй байх.** `2026.11.05`, `2026-11-05`, Excel-ийн серийн тоо, мянгатын зайтай `1 200` бүгд зөв уншигдах ёстой. Алдаатай мөрийг мөрийн дугаартай нь буцаана → Даалгавар 9.
4. **Холбооны хэрэглэгч хүснэгтэд шууд хандах.** `receipts` хүснэгтээс 0 мөр авах ёстой → Даалгавар 1, 10.
5. **Хүлээн авалтад холбогдсон төлөөлөгчийг устгах.** Устгахын оронд идэвхгүй болгох ёстой, түүх хадгалагдана → Даалгавар 3.

### Даалгавар 1: Өгөгдлийн сан ба RLS

**Файлууд:** `supabase/migrations/0001_schema.sql`, `0002_rls.sql`, `supabase/seed.sql`, `tests/db/rls.test.ts`

**Интерфейс (гаргана):** хүснэгтүүд
- `organizations(id uuid pk, name text, kind text check in ('factory','association'), share_with_association bool default true)`
- `memberships(user_id uuid → auth.users, org_id uuid, role text check in Role, pk(user_id, org_id))`
- `agents(id, org_id, full_name, register_no, card_no, aimag, soum, active bool default true)`
- `receipts(id, org_id, received_on date, padaan_no text, padaan_key text, agent_id → agents, herder_name text, herder_register text, aimag, soum, raw_type text, grade text, qty int check > 0, unit_price numeric(14,2), created_by uuid, created_at)` + индекс `(org_id, padaan_key)` (unique **биш**)
- `lots(id, org_id, receipt_id unique, raw_type)`
- `stage_moves(id, org_id, lot_id, from_stage, to_stage, qty_in int > 0, qty_out int >= 0 check qty_out <= qty_in, moved_on date)`
- `sales(id, org_id, lot_id, stage, qty int > 0, buyer, country, unit_price numeric(14,2), currency text default 'MNT', sold_on date)`
- `settings(org_id pk, subsidy_small numeric default 3000, subsidy_large numeric default 15000, dp_weights jsonb default '{"raw":0,"salted":0.1,"wet_blue":0.5,"crust":0.75,"finished":1}', grades text[] default '{1,2,3,Стандартын бус}')`
- SQL функц `is_member(org uuid, roles text[] default null) returns bool` (security definer)

RLS: бүх хүснэгтэд `using (is_member(org_id))`. Бичих эрх нь `receipts` хүснэгтэд admin, receiver; `stage_moves` хүснэгтэд admin, technologist; `sales` хүснэгтэд admin, accountant; `agents`, `settings` хүснэгтэд admin. `association` эрхтэй хэрэглэгчид эдгээр хүснэгтэд нэг ч бодлого байхгүй.
