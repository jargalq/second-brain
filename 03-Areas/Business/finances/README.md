# finances — санхүү

- Энд: **ажлын/багийн** санхүүгийн бичлэг (нэхэмжлэх, төлбөр, зардал) — загвар `Finance Record` (`scope: team`).
- `private/` дотор: 🔒 **хувийн** санхүү (сарын төлбөр, зээл, хувийн зардал) — [[03-Areas/Business/finances/private/README|private README]]-г унш.
- Хувийн зүйлийг энэ хавтасны үндсэнд бүү бич.

## Компани ба хувийн зааг

Компанийн данснаас хувийн данс руу орсон мөнгө бүр **дөрвөн төрлийн аль нэг** байна. Төрөлгүй шилжүүлэг гэж байхгүй — банкны баримтаас ийм гүйлгээ олдвол агент Mugi-ээс төрлийг нь асууна:

| Төрөл | Компанийн талд | Хувийн талд |
|---|---|---|
| **Цалин** | `kind: salary` зарлага (НДШ, ХХОАТ суутгаад) | `kind: salary`, `flow: in` |
| **Ногдол ашиг** | ашгаас, шийдвэртэй (10% татвар) | орлого |
| **Зээл (захиралд)** | авлага `state: forecast` — буцааж төлнө | өр |
| **Зардлын нөхөн олговор** | баримттай компанийн зардал | хувиасаа төлсөн зардлыг нөхөх |

- Компанийн зардлыг хувийн данснаас, хувийн зардлыг компанийн данснаас **төлөхгүй**.
- Хувийн бичлэгт компанийн шилжүүлгийг `private/`-д, компанийн талыг компанийн хавтаст — хоёр талд нь бүртгэнэ.
