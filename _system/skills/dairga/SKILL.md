# dairga: Зүүн нарангийн ТЭЗҮ-ийн зураг

4. Байрзүй: `ZuunNaran.dwg` → DXF (`dwg2dxf.ps1`). Блок модел: `C:\Users\Hp\Desktop\ХӨХ ТОЙН\2 zuun naran\block_model_2026-11-02\`.
5. Гаргасан файл: `C:\Users\Hp\Desktop\ХӨХ ТОЙН\2 zuun naran\zurag_2026-11-02\`. Шинэ хувилбарыг `_vN` дугаартай гаргана, хуучныг дарж бичихгүй.

## 3. Гаргах команд
```
bash _regen_all.sh            # жил 1–5, №5, №5 DXF, №6, №8 (SVG/HTML)
python -I zn_drawings.py topo/ZuunNaran.dxf z24_out        # №2–4
```
Дараа нь:
- **PDF:** HTML бүрийг Edge headless-ээр scratchpad дотор хэвлэнэ (`--print-to-pdf`, `--no-pdf-header-footer`), дараа нь гаралтын хавтас руу `Copy-Item`.
- **DWG:** `dxf2dwg_groups.ps1 -Dxf <...>.dxf -Dwg <...>.dwg` (ерөнхий дэвсгэр, жил 1–5). Мөр бүрийн «groups N, grouped M»-ийг шалгана.
- **Шалгах:** `pdf2png.ps1`-ээр PNG (≤ 4000 px, том нь гацдаг), PIL-ээр тайрч нүдээр харна.
- Нэг жилийн тооцоо ≈ 2–3 мин, бүгд ≈ 15–20 мин. Арын горимд ажиллуулна.

- **Олборлолт:** 2 ээлж → [[2026-11-03 - Зүүн наран олборлолт 2 ээлжтэй]]
- **Өвлийн нөөц** Хармагтайн гэрээгээр багассан (агуулах 17 608 м³) → [[2026-11-03 - Зүүн наран өвлийн нөөцийг Хармагтайн гэрээгээр багасгах]]
- **Кемп:** зүлгийн оронд говийн ургамал, сагсны талбай, зогсоол → [[2026-11-03 - Зүүн наран кемпэд зүлгийн оронд говийн ургамал]]
