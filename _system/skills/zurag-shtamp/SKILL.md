## Хэрэглээ (python, SVG мм) — `zn_stamp.py`
Ажиллах модуль нь `_system/skills/zurag-uurhai/scripts/zn_stamp.py` (Mugi 2026-11-13: «zn_stamp.py руу заа»). Бүх ТЭЗҮ-ийн зураг (Зүүн, Баруун наран) үүгээр штамптай гардаг.
```python
import sys; sys.path.insert(0, r"D:\Second brain\_system\skills\zurag-uurhai\scripts")
import zn_stamp as S
# Төсөл бүрт эдгээрийг солино (анхдагч нь Зүүн наран):
S.CLIENT = '«ХӨХ ТОЙН» ХХК'
S.PROJECT = ['Өмнөговь аймгийн Цогтцэций сумын нутагт', 'орших «Зүүн наран» барилгын чулууны',
             '(андезит) ордыг ил аргаар ашиглах', 'техник, эдийн засгийн үндэслэл']
S.LICENSE = 'MV-46000368'
# A1 (841 × 594 мм), хүрээ 5 мм → баруун доод булан (836, 589)
svg_lines = S.stamp(836, 589, ['1-р жилийн уулын ажлын', 'төлөвлөгөөний зураг'],
                    paper='A1', scale='1:1000', sheet_no='7', total='19')
page_svg_body.extend(svg_lines)   # мм нэгжтэй <svg viewBox="0 0 841 594"> дотор
```
- `x_right`, `y_bottom` нь хүрээний баруун доод булан (мм, SVG-ийн y доошоо өснө). A3 (420 × 297), хүрээ 5 мм бол (415, 292).
- Гарын үсгийн хоёр инженер (`S.SIGNERS`), яамны нэр (`S.AUTHORITY`) модульд бий. Хэрэглэгч хэлэхгүй бол солихгүй.
- Зургийн нэрийг `title_lines` жагсаалтаар мөр мөрөөр өгнө. Фонт автоматаар багасдаггүй тул урт мөрийг өөрөө таслана.
- Зургийн талбайг штампын дээгүүр (доод хил ≥ 62 мм) байрлуулна. Баруун самбарын бичвэр ч штамптай давхцахгүй байх ёстой.
- matplotlib-д зориулсан `gv_stamp.draw_stamp` хэзээ ч байгаагүй (2026-11-12 туршилт: `ModuleNotFoundError`). Хуучин жишээ: `_trash/skills-2026-11-13/zurag-shtamp/SKILL.before-zn_stamp.md`.
- Жишээ: `_system/skills/zurag-uurhai/scripts/zn_year1.py`, `zn_trench_passport.py` (бүгд `zn_stamp`-ийг ашигладаг). Хуучин жишээ `ZN_1-r_jil_zurag.py` (`D:\PARA\1-Projects\Great Vision project\069 Khukhtoin\…`) 2026-11-13-нд `D:\PARA`-д олдсонгүй.
