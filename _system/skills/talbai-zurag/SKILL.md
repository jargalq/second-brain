# Талбайн 7 зураг

Тусгай зөвшөөрлийн булангийн солбицлоос БОННҮ, төлөв байдлын тайланд хэрэгтэй 7 зургийг нэг командаар гаргана. Загвар нь MILLION төслийн `bulgan_bureghangai_23` зургууд: зүүн талд аймаг (сум шараар), баруун дээд талд сум, доод талд талбайн ойрын зураг, баруун доод буланд «ТАЙЛБАР». Mugi 2026-11-12-нд Хүрэн ганга, Зүүн наранд туршиж баталсан.

## Оролт (хэрэглэгчээс)

| Талбар | Жишээ | Тайлбар |
|---|---|---|
| ТЗ-ийн дугаар | MV-46000368 | |
| Нэр | Зүүн наран | Файлын нэр, гарчигт орно |
| Эзэмшигч | Хөхтойн ХХК | Агаарын зурагт |
| Талбай, га | 148.94 | ТЗ-ийнхийг бичнэ; скрипт солбицлоор тулгана |
| Булангийн солбицол | 105° 55' 22.3'' · 43° 46' 34.5'' | **Хэрэглэгчийн дугаарласан дарааллаар** (1, 2, 3, …). Хэлбэр ямар ч байж болно: `105° 55' 22.3''`, `105°55′22.3″`, `105.9229` |

Аймаг, сумыг солбицлоор өөрөө олно. Хэрэглэгчийн хэлсэн сум зөрвөл **зөрүүг хэлж асуу** (Хүрэн гангад «Булган» гэсэн ч солбицол Гурванбулагт буусан, Mugi Гурванбулаг зөв гэв). Солбицол алга бол vault-аас хай: `Grep "MV-<дугаар>"` эсвэл төслийн «ТЭЗҮ 02 - Ерөнхий мэдээлэл».

## Ажиллуулах

1. Scratchpad-д `config.json` бич (UTF-8):
   ```json
   {"name": "Зүүн наран", "license": "MV-46000368", "holder": "Хөхтойн ХХК", "area_ha": 148.94,
    "out": "D:/PARA/1-Projects/<төсөл>/04 Байгаль орчин/Зураг - <Нэр>",
    "corners": [["105°55'22.3\"", "43°46'34.5\""], ["105°55'22.3\"", "43°47'5.5\""],
                ["105°54'12.64\"", "43°47'5.5\""], ["105°54'12.64\"", "43°46'34.5\""]]}
   ```
2. `py -3 -I "<vault>/_system/skills/talbai-zurag/talbai_zurag.py" config.json` (≈2–4 мин). Нэг зураг л: `--only 0` (0 агаар … 6 УТХГ, жишээ `--only 3,5`).
3. Гаралтыг унш: солбицлоор бодсон талбай ↔ ТЗ-ийн талбай, аймаг/сум, талбай дээрх хөрс, ургамал, гүний ус, хамгийн ойр 3 УТХГ (км).
4. 1–2 зургийг жижигрүүлж Read-ээр харж шалга.
5. Telegram-аар явуулах бол `reply` + `files` (chat_id: Mugi-ийнх).

## Хаана хадгалах

- `out` = тухайн төслийн `D:\PARA\1-Projects\...\<төсөл>\04 Байгаль орчин\Зураг - <Нэр>\`. Талбай аль төслийнх болохыг эзэмшигчээр нь ол (МБГЦ → `079 МБГЦ`, Хөхтойн → `069 Khukhtoin`). Олдохгүй бол асуу. MILLION хавтсанд бүү хий.
- Файлууд: `0_агаарын зураг_<Нэр>.jpg`, `1_сансар_…`, `2_гүний ус_…`, `3_гадаргуу_…`, `4_хөрс_…`, `5_ургамалжилт_…`, `6_тусгай хамгаалалттай газар_…`.
