# Уул уурхайн төслийн note (vault)

Vault: `D:\Seond brain` — эхлээд `CLAUDE.md` (дүрэм) уншина. ТЭЗҮ-ийн ажлын урсгал, бүлгийн дараалал: **REQUIRED SUB-SKILL:** `tezu`. Энэ skill зөвхөн «note хаана, ямар нэр, ямар frontmatter-тэй» гэдгийг хариулна.

## Хаана байна
```
02-Projects/
├─ Төслүүд.md                 самбар (хүснэгт) — шинэ төсөлд мөр нэмнэ
├─ Төслийн нэгтгэл.base       file.inFolder("02-Projects/Ажил") + hasProperty("баримт")
└─ Ажил/<Захиалагч> ХХК/
   ├─ <Захиалагч> ХХК - төсөл.md   (олон ордтой бол нэгтгэл note)
   └─ <Орд>/
      ├─ <Орд> - ....md            төслийн note (жишээ «Баруун наран - ашиглалт 2027»)
      ├─ ТЭЗҮ/                     ← А: бүлэг бүр тусдаа note
      └─ 1 ТЭЗҮ/, 2 Байгаль орчин/ ← Б: баримт бүр нэг note
```
Ажлын эх файл (docx, xlsx, dwg) vault-д биш: `D:\Great Vision project\NNN <Орд>\`, note-ийн `хавтас:` property-д заана. Тэнд устгах, зөөхгүй, шинэ хувилбарыг шинэ нэрээр.

Note олох: Glob `02-Projects/Ажил/**/*<Орд>*`; бүлэг бол `02-Projects/Ажил/**/*<ТТ> ТЭЗҮ 04 -*`, индекс бол `*<ТТ> 00 -*`. Зүүн наран товчлолгүй (`ТЭЗҮ 04 - …`, `00 - ТЭЗҮ индекс…`) — зөвшөөрөлгүй нэрийг нь солихгүй.

## Хоёр бүтэц — аль нь
| | А. ТЭЗҮ-г vault-д бичиж буй (Хөхтойн) | Б. Баримтын явц хянах (Баянгийн их ам, Онгон хайрхан-1) |
|---|---|---|
| Хавтас | `<Орд>/ТЭЗҮ/` | `<Орд>/1 ТЭЗҮ/01 Хайгуулын тайлан · 02 ТЭЗҮ · 03 Усны дүгнэлт`, `2 Байгаль орчин/01 Төлөв байдлын тайлан · 02 Усны дүгнэлт · 03 БОННҮ` |
| Нэр | `<ТТ> 00 - ТЭЗҮ индекс, гол үзүүлэлт.md`, `<ТТ> ТЭЗҮ NN - <Бүлэг>.md` (NN = 01–11) | `<Орд> - <Баримт>.md` |
| Base-д | гарахгүй (`баримт` байхгүй) | «Төслийн нэгтгэл»-д гарна |

Шинэ орд: ТЭЗҮ-г vault-д бичих бол **А** (анхдагч), зөвхөн явц хянах бол Б — эргэлзвэл нэг асуултаар батлуул.
`<ТТ>` = ордын нэрийн үгсийн эхний үсэг (Баруун наран → БН, Улаан овоо → УО). Нэр vault даяар давхардахгүй байх ёстой тул Glob `**/<ТТ> 00 -*`-аар давхардал шалгаж, хэрэглэгчээр батлуул.
Компанийн хавтас хавтгай байвал (Гурвансайхан ХХК) `<Орд>/` дэд хавтас шинээр үүсгэнэ; байгаа note-ийг зөвшөөрөлгүй зөөхгүй.

## Frontmatter
Төслийн note (`<Орд>/<Орд> - <зорилго>.md`, нэрийг хэрэглэгчээр батлуул):
```yaml
төрөл: төсөл
type: project
төлөв: идэвхтэй
эхэлсэн: YYYY-MM-DD
хүрээ: Уул уурхай
захиалагч: «<Захиалагч>» ХХК
хавтас: "file:///D:/Great%20Vision%20project/<NNN%20Орд>"
tags: [төсөл, орд, ТЭЗҮ, <Захиалагч>]
```
А, индекс:
```yaml
төрөл: ТЭЗҮ
төлөв: бичиж буй
огноо: YYYY-MM-DD
хувилбар: v1 (markdown ноорог)
холбоотой: "[[<төслийн note>]]"
prompt: "[[ТЭЗҮ агент]]"
tags: [ТЭЗҮ, <Орд-зураастай>]
```
А, бүлэг:
```yaml
төрөл: ТЭЗҮ-бүлэг
type: tezu-chapter
date: YYYY-MM-DD
ai-first: true
төлөв: ноорог
бүлэг: 4
холбоотой: "[[<ТТ> 00 - ТЭЗҮ индекс, гол үзүүлэлт]]"
tags: [ТЭЗҮ, <Орд-зураастай>]
```
Б, баримт:
```yaml
төсөл: "[[<Орд>]]"
шат: ТЭЗҮ            # эсвэл Байгаль орчин
баримт: ТЭЗҮ         # Хайгуулын тайлан · Усны дүгнэлт · Төлөв байдлын тайлан · БОННҮ
төлөв: Эхлээгүй
гүйцэтгэгч: Грийтвишн ХХК   # БОННҮ → Грийтвишн Инженеринг ХХК; төлөв байдал, ус → хоосон
хариуцагч:
эхэлсэн:
дууссан:
хууль: ["[[Түгээмэл тархацтай ашигт малтмалын тухай хууль]]"]
up: "[[<төслийн note-ийн бүтэн зам>]]"
```
Хууль: барилгын чулуу, элс хайрга → Түгээмэл тархацтай АМ-ын хууль; бусад орд → Ашигт малтмалын тухай хууль; ТЭЗҮ, БОННҮ → Байгаль орчныг хамгаалах тухай; ус → Усны тухай. Заалтыг санамжаас бүү баталгаажуул.

## Тоо өөрчлөгдөхөд
Индекс = тооны нэг эх сурвалж. Эхлээд индексийн мөрийг засна → шийдвэрийн атом `04-Resources/Atomic/decisions/YYYY-MM-DD - <нэр>.md` → бүлгүүдийг `tezu`-ийн дарааллаар (4 → 5 → 10 → 7–9 → 2 → 1, 11), бүлэг бүрийн дараа хэрэглэгчээр батлуулна → төслийн note-ийн «Явцын бүртгэл»-д мөр нэмнэ → `Төслүүд.md`-ийн мөрийг шинэчилнэ. Шинэ тоо өмнөх шийдвэртэй зөрвөл (жишээ нь хүчин чадал × хугацаа ≠ нөөц) бичихээс өмнө хэрэглэгчид хэл.

## Түгээмэл алдаа
- `C:\Users\User\Documents\Obsidian Vault`, `Төслүүд/Уул уурхай/` — хуучин бүтэц, байхгүй.
- Бүлгийг Б-ийн нэг `<Орд> - ТЭЗҮ.md` дотор хайх — А бүтэцтэй ордод бүлэг тусдаа файл.
- Хэрэглэгчийн зассан note-ийг дарж бичих — засахын өмнө файлыг шинээр унш.

- «Гриит Вишн», «ГРЭЙТ ВИЖН» — зөв нь «Грийтвишн» ХХК.
