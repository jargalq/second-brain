# D:\Inbox → Obsidian Inbox

- `D:\Inbox` хавтсанд (дэд хавтсуудыг оролцуулан) файл хийхэд `inbox_sync.py` тухайн файл бүрд `01-GTD/Inbox/<файлын нэр>.md` тэмдэглэл үүсгэнэ.
- Тэмдэглэлд дараах зүйлс орно:
  - файлын холбоос
  - хэмжээ, огноо
  - эхний хэсэг (txt, docx, pdf файлаас)
  - ангилах мөр
- Эх файлыг зөөхгүй, устгахгүй. Аль хэдийн бүртгэсэн файлыг `state.json`-д хадгална, тиймээс давхардахгүй.
- Хянах хавтсыг нэмэх бол скриптийн `WATCH` жагсаалтад нэмнэ.
- Ажиллах үе:
  - `inbox` командын эхэнд.
  - Task Scheduler-т **«Obsidian Inbox sync»** нэрээр 15 минут тутам ажиллахаар бүртгэсэн (2026-10-30). `pythonw` ашигладаг тул цонх гарч ирэхгүй.
    - Зогсоох: `Disable-ScheduledTask -TaskName 'Obsidian Inbox sync'`
    - Устгах: `Unregister-ScheduledTask -TaskName 'Obsidian Inbox sync'`
