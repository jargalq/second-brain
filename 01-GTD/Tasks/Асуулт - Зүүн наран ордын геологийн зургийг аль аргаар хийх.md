# Асуулт: Зүүн наран ордын геологийн дэвсгэр зургийг аль аргаар хийх

## For future agent

Сешн 473fd3e8 (огноо digest-д алга; 2026-11-13-ны «update all»-аар хураагдсан) Хөтлийн шарын №1 «Ордын геологийн дэвсгэр зураг» (1:1000)-ийг загвар болгон Зүүн наранд хэрэглэхээр харсан. Зүүн нарангийн эх сурвалж нь нөөцийн тайлангийн «3. Ордын геологийн зураг» (1:5000; aQ₂, N₂, C₂do гурван нэгж). Тэр PDF вектор биш, зөвхөн растер зураг (63 МБ) тул геологийн хилийг шууд уншиж авах боломжгүй. Сешн файл засаагүй. Mugi хариулаагүй. Хариу ирмэгц шийдвэрийн атом бичиж, ажлын task нээнэ.

## Асуулт

1. **Растерыг геолавлаад (georeference) хилийг дахин зурах.** Хилийг UTM координатаар вектор болгож, бусад зургийн адил MNS 6302-ийн өнгө, хээ, штамп, DWG-тэй гаргана. Сешний үнэлгээгээр нэг өдөр орчим; зурсан хилийг Mugi эх зурагтай тулгаж шалгана.
2. **Нөөцийн тайлангийн геологийн зургийг шууд хавсаргах.** Эх зургийг дэвсгэр болгож, хүрээ, штамп, уурхайн хилийг нэмнэ. Хурдан, гэхдээ DWG гарахгүй, хэв маяг бусад зурагтай таарахгүй.

Сешний санал: 1-р арга.
