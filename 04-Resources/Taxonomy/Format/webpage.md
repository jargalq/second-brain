> **itge.e-ийн ангилал.** Юу болохыг тодорхойлсон note; `Ангилал.base` дээр бүгд хүснэгт болно. Өөрт тохирохгүйг нь устгаад, дутууг ижил хэлбэрээр нэм.

# 🌐 Вэб хуудас

**Тэнхлэг:** `format:` — контент ямар хэлбэртэй вэ.

## Юу вэ
Хөтөч дээр нээгддэг HTML хуудас: клиентийн сайтын хуудас, уншвар, прототип, нийтэлсэн гаралт.

## Хэзээ хэрэглэх
Гаралт нь HTML хуудас (эсвэл хуудсуудын багц) бол `format: webpage` гэж бичнэ. Хуудас нь Figma frame, HTML эх хувь, Vercel хаяг гэсэн олон гадаргуутай байж болох тул гадаргуу бүрийг `surfaces:`-д бүртгэнэ → .

## Урсгал
1. Гаралтад `format: webpage` тавина.
2. `surfaces:`-д figma / html / vercel / github тус бүрийн зам, URL, төлөвийг бичнэ.
3. Амьд хаягийг нийтлэхээсээ өмнө шалгаад (HTTP статус) бүртгэнэ.
