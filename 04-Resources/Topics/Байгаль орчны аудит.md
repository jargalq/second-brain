# Байгаль орчны аудит

## For future agent

Уурхайн төслийн хоёр жил тутмын байгаль орчны аудит: хуулийн шаардлага, журам, эрх бүхий байгууллага, гэрээ. Анхны жишиг нь Рич майнинг ХХК («Уулбаян», MV-022815), 2026-11. БОМТ, БОННҮ-д «аудитыг 2 жил тутам хийлгэх» арга хэмжээ байдаг тул БОМТ-ний биелэлтийн тайлантай холбоотой.

## Одоо бид юу мэдэх вэ

- **Хууль:** Байгаль орчныг хамгаалах тухай хуулийн 10¹ дүгээр зүйл. Байгалийн нөөц ашигладаг аж ахуйн нэгж аудитыг 2 жил тутам хийлгэж, зөвлөмжийг хэрэгжүүлэн, зөвлөмжид заасан хугацаанд тайлангаа аймаг, нийслэлийн байгаль орчны албанд хүргүүлнэ (10¹.1). Төлөвлөгөөт аудитын зардлыг аж ахуйн нэгж өөрөө хариуцна (10¹.2). Тодорхойлолт нь 3.2.14-т байна → [legalinfo.mn](https://legalinfo.mn/mn/detail?lawId=8935).
- **2026-07-03-ны өөрчлөлт:** аудит хийх хуулийн этгээд байгаль орчны бусад тусгай зөвшөөрөлтэй ажлыг давхар эрхлэхгүй (10¹.6). Гүйцэтгэх удирдлага нь аудитор байх, 3-аас доошгүй орон тооны аудитортай байх (10¹.7). Аудитор нь 5-аас доошгүй жил ажилласан, сургалтад хамрагдаж гэрчилгээ авсан байна (10¹.8).
- **Журам:** БОАЖ-ын сайдын 2019 оны А/809 («аудит хийх эрх олгох журам», «ерөнхий аргачлал») тушаалыг 2023-09-18-ны А/453-аар хүчингүй болгосон. Орлох журам legalinfo.mn, яамны сайтаас олдоогүй. Яамны сайт А/809-ийг одоо ч жагсаалтдаа харуулдаг → [legalinfo.mn](https://legalinfo.mn/mn/detail/14977).
- **Эрх бүхий байгууллага:** яамны жагсаалтад 32 компани байгаа бөгөөд хамгийн сүүлийн бичлэг нь 2024-01-29-нийх. Грийн гоулд девелопмент жагсаалтад алга → [mecc.gov.mn](https://mecc.gov.mn/documents/bajgal-orchny-audit-hijh-erh-b-hij-azh-ahujn-negzh-d?sort=date&order=desc). Лавлах: яам, 51-261966, contact@mecc.gov.mn.
- **Хараат бус байдал:** аудит бол «хараат бус үйл ажиллагаа» (3.2.14). Тухайн аж ахуйн нэгжийн БОМТ, БОННҮ, ТЭЗҮ-г боловсруулсан компани (жишээ нь Грийтвишн) өөрийн ажлыг аудитлахгүй.
- **Гэрээ:** Иргэний хуулийн 343–358 (ажил гүйцэтгэх). Алданги хоног тутам 0.5 хувиас, анзын нийт дүн 50 хувиас хэтрэхгүй (232.4, 232.6). Захиалагч гэрээг хэдийд ч цуцалж болох ч хохирлыг нөхөн төлнө (355.2, 355.6).
- **Жишиг гэрээ:** Рич майнинг ↔ Грийн гоулд девелопмент, 45 хоног, 18 сая ₮ (НӨАТ орсон), 60/40 → `02-Projects/Ажил/Рич майнинг ХХК/Рич майнинг - Байгаль орчны аудитын гэрээ (төсөл).docx`, [[2026-11-02 - Рич майнинг аудитын гэрээний талууд]].
- **Хаана гардаг:** Рич майнингийн 2025 оны БОМТ-ний биелэлт («2026 онд аудит хийлгэнэ»), Тодбумын БОННҮ ба БОМТ-ний материалын жагсаалт (9.3) → [[Тодбум - БОМТ 2026 биелэлтийн тайлан]].

## Холбогдсон (`topics:`)

> Note-ийн `topics:`-д энэ сэдвийг бичвэл энд автоматаар гарна.

```base
filters:
  and:
    - 'list(topics).toString().contains(this.file.name)'
    - 'file.ext == "md"'
views:
  - type: table
    name: Шийдвэр
    filters:
      and:
        - 'type == "atomic" || type == "session-decision"'
    order: [file.name, date]
    sort:
      - property: file.name
        direction: DESC
  - type: table
    name: Бүгд
    filters:
      and:
        - 'file.name != this.file.name'
    order: [file.name, date]
    sort:
      - property: file.name
        direction: DESC
```
