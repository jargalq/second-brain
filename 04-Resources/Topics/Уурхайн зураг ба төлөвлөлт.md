# Уурхайн зураг ба төлөвлөлт

## For future agent

ТЭЗҮ-ийн хавсралт зураг (ерөнхий дэвсгэр, жилийн уулын ажил, овоолго, паспорт, нөхөн сэргээлт) ба уурхайн хил, эзлэхүүний тооцооны сэдэв. Анхны жишиг нь Зүүн наран (Хөх тойн ХХК, андезит, 2026-10/11). Зурах ажлын урсгал [[_system/skills/zurag-uurhai/SKILL|zurag-uurhai]], төслийн тохиролцоо [[_system/skills/dairga/SKILL|dairga]], сешн эхлүүлэх заавар [[_system/Заавар - ТЭЗҮ, зургийн сешн эхлүүлэх]].

## Одоо бид юу мэдэх вэ

- **Стандарт:** MNS 6302:2011. Хүрээ зүүн 20 / бусад 5 мм, масштаб зөвхөн 1:200…1:10 000, хөмсөг 0.4 / ул 0.2 мм, налуу шугам урт–богино ээлжилнэ, налуу (italic) шрифт → [[Уул уурхайн график зургийн стандарт (MNS 6302)]].
- **Штамп:** Грийтвишн загвар 185 × 55 мм, 2 инженер (Ч.Аръяабал, Т.Давааням), нийт хуудас нэгдсэн (19) → [[2026-10-30 - Зургийн штамп Грийтвишн загвараар]].
- **Хэв маяг:** жилээр өнгөөр ялгахгүй; зам шар, бодит өргөнтэй; овоолго ногоон, дугуйрсан, налуу шугамтай, V/S/өндөр бичигдэнэ; A1 дээр нэг үндсэн масштаб, цонх зөвхөн шаардлагатай үед.
- **Уурхайн булан:** ёроолд R 5 м, амсарт R ≈ 29 м (төвтэй тойрог), бүх буланд. Дугуйлбал нөөц ≈ 0.5 % буурдаг тул хананы байрлалыг эзлэхүүнээр дахин тулгана.
- **Эзлэхүүн:** үйлдвэрлэлийн нөөц = андезит − 5 см дээвэр + 10 см ёроол; блок моделоор тулгана (шатлалтай хана ба шулуун 40° хананы ялгаа ≈ 13.6 мян м³) → [[2026-11-03 - Зүүн наран уурхайн баруун ханыг 5 м зөөх]].
- **Техник:** R380LC-9, HOWO, SD-13-ийг бодит хэмжээгээр, шугамаар зурна (`zn_equip.py`).
- **Гаралт:** python SVG → PDF (Edge), group-тэй DWG (AutoCAD); шинэ хувилбар `_vN`, хуучныг дарж бичихгүй.

## Холбогдсон (`topics:`)

> Note-ийн `topics:`-д энэ сэдвийг бичвэл энд автоматаар гарна.

```base
filters:
  and:
    - 'list(topics).toString().contains(this.file.name)'
    - 'file.ext == "md"'
views:
  - type: table
    name: Шийдвэр
    filters:
      and:
        - 'type == "atomic" || type == "session-decision"'
    order: [file.name, date]
    sort:
      - property: file.name
        direction: DESC
  - type: table
    name: Бүгд
    filters:
      and:
        - 'file.name != this.file.name'
    order: [file.name, date]
    sort:
      - property: file.name
        direction: DESC
```
