# library — номын сан

Ном, курс, урт материал. Уншсан зүйлээс гарсан санааг атом болгоно.

Эндээс эхэл: **[[04-Resources/library/Ном ↔ зарчим ↔ дүрэм]]** — fm-ийн дүрэм бүр аль номын
зарчмаас гарсныг харуулсан зураглал. Ном бүрийн «зарчмын хуудас» нь бүтэн хураангуй биш,
харин *энэ ном fm-д юу болсон бэ* гэдгийг хэлнэ:

| Түлхүүр | Хуудас |
|---|---|
| `basb` | [[04-Resources/library/Building a Second Brain - Tiago Forte]] |
| `para` | [[04-Resources/library/The PARA Method]] |
| `gtd` | [[04-Resources/library/Getting Things Done - David Allen]] |
| `atomic-habits` | [[04-Resources/library/Atomic Habits - James Clear]] |
| `zettelkasten` | [[04-Resources/library/Zettelkasten - How to Take Smart Notes]] |
| `bmg` | [[04-Resources/library/Business Model Generation - Alexander Osterwalder]] |

Хоёр нэмэлт хуудас:

- **[[04-Resources/library/Уншвар - Second Brain Season 2]]** — нийтлэгдсэн урт уншварууд
  (`itge-intro.vercel.app`): ямар гацалтад аль уншвар. Гацвал **эхлээд энд** хар.
- **[[04-Resources/library/Унших жагсаалт]]** — юу уншихын дараалал: зургаан суурь ном +
  гүнзгийрүүлэх үнэгүй эх сурвалж. Эх хувилбар (PDF/EPUB) загвартай хамт явдаггүй.

`/fm:help` «яагаад ингэж ажилладаг вэ» гэсэн асуултад эдгээрээс иш татаж хариулдаг.
Номоо өөрөө уншиж эхэлбэл гол санаа бүрийг атом болгоод тухайн хуудаснаас холбо —
дараагийн удаа тусламж чиний өөрийн үгээр ирнэ.
