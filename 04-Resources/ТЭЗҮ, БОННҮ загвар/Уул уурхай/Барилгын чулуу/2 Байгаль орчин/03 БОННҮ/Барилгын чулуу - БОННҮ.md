## Гол нөлөөллүүд
- Тэсэлгээ, бутлалтын тоос, чичиргээ
- Дуу чимээ (хөрөө, бутлуур)
- Ландшафтын өөрчлөлт
- Цацраг идэвхт байдал (чулуулгаас хамаарна)

## Бууруулах гол арга хэмжээ
- Тэсэлгээний горим, суурьшлаас зай
- Тоос дарах, дуу чимээний хаалт
- Цацрагийн хэмжилт
- Карьерын нөхөн сэргээлт

## Үе шат
- [ ] Ерөнхий үнэлгээ хийлгэж, дүгнэлт авсан
- [ ] Грийтвишн инженеринг ХХК-тай гэрээ байгуулсан
- [ ] Хээрийн судалгаа, сорьцлолт хийсэн
- [ ] Орон нутгийн иргэдтэй зөвлөлдсөн, саналыг авсан
- [ ] Тайлан бэлэн болсон
- [ ] Байгаль орчны асуудал хариуцсан төрийн байгууллагад хүргүүлсэн
- [ ] Шинжээчийн дүгнэлт гарсан, засвар оруулсан
- [ ] Батлагдсан

## Тайлангийн бүлгүүд

### 1. Удиртгал
- [ ] Үнэлгээний зорилго, хамрах хүрээ, хууль эрх зүйн үндэслэл
- [ ] Ерөнхий үнэлгээний дүгнэлт, даалгавар
- [ ] Үнэлгээ хийсэн байгууллага: Грийтвишн инженеринг ХХК, мэргэжилтнүүд
- [ ] Ашигласан арга зүй

### 2. Төслийн тодорхойлолт
- [ ] Төслийн тойм, хүчин чадал, хугацаа → [[Барилгын чулуу - ТЭЗҮ]]
- [ ] Байршил, талбайн хэмжээ, тусгай зөвшөөрөл
- [ ] Технологи, үйл ажиллагааны үе шат (бэлтгэл, ашиглалт, хаалт)
- [ ] Ус, эрчим хүч, түүхий эд, химийн бодисын хэрэглээ
- [ ] Хаягдал, бохирдлын эх үүсвэр

### 3. Байгаль орчны суурь нөхцөл
- [ ] Суурь төлөв байдал → [[Барилгын чулуу - Төлөв байдлын тайлан]]
- [ ] Уур амьсгал, агаарын чанар
- [ ] Газарзүй, гадаргын хэлбэр, геологи
- [ ] Хөрс
- [ ] Гадаргын ба газрын доорх ус → [[Барилгын чулуу - Усны дүгнэлт (БОННҮ)]]
- [ ] Ургамлан нөмрөг, ан амьтан (ховор, нэн ховор зүйл)
- [ ] Тусгай хамгаалалттай газар, голын хамгаалалтын бүстэй давхцал
- [ ] Хүн ам, нийгэм, эдийн засаг, эрүүл мэнд
- [ ] Түүх, соёлын дурсгал

### 4. Төслийн хувилбарууд
- [ ] Байршил, технологийн хувилбарууд
- [ ] Төсөл хэрэгжихгүй байх хувилбар
- [ ] Сонгосон хувилбарын үндэслэл

### 5. Нөлөөллийн үнэлгээ
- [ ] Агаарын чанар
- [ ] Гадаргын болон газрын доорх ус
- [ ] Хөрс, газрын гадарга
- [ ] Ургамал, ан амьтан
- [ ] Дуу чимээ, чичиргээ
- [ ] Ландшафт
- [ ] Нийгэм, эрүүл мэнд, мал аж ахуй
- [ ] Хуримтлагдах нөлөөлөл
- [ ] Нөлөөллийн ач холбогдлын үнэлгээ (хүрээ, хугацаа, эрчим)

### 6. Эрсдэлийн үнэлгээ
- [ ] Осол, асгаралт, гал түймэр
- [ ] Байгалийн гамшиг (үер, газар хөдлөл)
- [ ] Эрсдэлийн менежментийн төлөвлөгөө

### 7. Сөрөг нөлөөллийг бууруулах арга хэмжээ
- [ ] Бүрэлдэхүүн тус бүрээр арга хэмжээ
- [ ] Хугацаа, хариуцагч, зардал

### 8. Байгаль орчны менежментийн төлөвлөгөө
- [ ] Байгаль орчныг хамгаалах төлөвлөгөө
- [ ] Нөхөн сэргээлтийн төлөвлөгөө (техникийн, биологийн)
- [ ] Хяналт-шинжилгээний хөтөлбөр (цэг, үзүүлэлт, давтамж)
- [ ] Хаалтын дараах арга хэмжээ
- [ ] Зардлын нийт тооцоо

### 9. Олон нийтийн оролцоо
- [ ] Олон нийтийн хэлэлцүүлэг, оролцогчид
- [ ] Сум, баг, Иргэдийн Төлөөлөгчдийн Хурлын санал
- [ ] Санал, гомдол ба тэдгээрийн хариу

### 10. Дүгнэлт, зөвлөмж
- [ ] 

### Хавсралт
- [ ] Байршлын зураг, нөлөөллийн бүсийн зураг
- [ ] Лабораторийн шинжилгээний дүн
- [ ] Гэрэл зураг
- [ ] Албан бичиг, санал, хэлэлцүүлгийн тэмдэглэл
