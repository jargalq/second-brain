## Онцлог анхаарах зүйлс
- Хүдрийн биетийн хэлбэр, уналт, зузаан
- Агуулга (г/т), тогтворгүй тархалт (nugget effect)
- Хүдрийн эрдэс найрлага: чөлөөт алт ба сульфидтэй холбоотой алт
- Ил эсвэл далд ашиглалтын хил

## ТЭЗҮ-ийн бүлгүүд

### 1. Ерөнхий мэдээлэл
- [ ] Төслийн зорилго, үндэслэл
- [ ] Тусгай зөвшөөрөл, талбайн солбицол, хэмжээ
- [ ] Засаг захиргаа, газарзүйн байршил, уур амьсгал
- [ ] Дэд бүтэц: зам, эрчим хүч, суурин газар хүртэлх зай
- [ ] Өмнө хийгдсэн ажлууд

### 2. Геологи, нөөц
- [ ] Хайгуулын үр дүн → [[Алтны үндсэн орд - Хайгуулын тайлан]]
- [ ] Ордын геологийн загвар, хүдрийн биетийн 3D загвар
- [ ] Блок загвар, агуулгын интерполяци
- [ ] Нөөцийн ангилал (батлагдсан, магадлалтай)
- [ ] Чулуулгийн физик-механик шинж, геотехник
- [ ] Нөөцийн бүртгэл, ЭБМЗ-ийн дүгнэлт

### 3. Уул уурхайн ажил
- [ ] Ашиглалтын систем сонголт (ил / далд / хосолсон), үндэслэл
- [ ] Уурхайн оновчлол, налуу өнцөг, ухалтын дэс
- [ ] Тэсэлгээний ажил, тэсрэх бодисын агуулах
- [ ] Хүдэр/хаягдал чулуулгийн харьцаа, бүтээмж (т/жил)
- [ ] Далд бол: нэвтрэлт, агааржуулалт, бэхэлгээ, ус шүүрүүлэх
- [ ] Тоног төхөөрөмжийн тооцоо
- [ ] Уурхайн ажлын календарь төлөвлөгөө

### 4. Баяжуулалт, боловсруулалт
- [ ] Технологийн туршилтын дүн (лабораторийн, хагас үйлдвэрийн)
- [ ] Бутлах, нунтаглах схем
- [ ] Гравитаци + цианжуулалт (CIL/CIP) эсвэл овоолгын уусгалт
- [ ] Цианидын менежмент, саармагжуулалт
- [ ] Хаягдлын сангийн зураг төсөл, далангийн тогтворжилт
- [ ] Металл авалтын хувь, Доре хайлш гаргах

### 5. Дэд бүтэц, туслах байгууламж
- [ ] Цахилгаан хангамж
- [ ] Ус хангамж, ус зайлуулалт → [[Алтны үндсэн орд - Усны дүгнэлт (ТЭЗҮ)]]
- [ ] Зам, тээвэр
- [ ] Ажилчдын байр, засварын газар, агуулах
- [ ] Шатахуун хадгалах, түгээх

### 6. Байгаль орчин, нөхөн сэргээлт
- [ ] Сөрөг нөлөөлөл, бууруулах арга хэмжээ
- [ ] Техникийн ба биологийн нөхөн сэргээлт, зардал
- [ ] Нарийвчилсан үнэлгээ → [[Алтны үндсэн орд - БОННҮ]]

### 7. Хөдөлмөрийн аюулгүй байдал, эрүүл ахуй
- [ ] Аюултай хүчин зүйлс, эрсдэлийн үнэлгээ
- [ ] Галын аюулгүй байдал, осол, ослын үеийн төлөвлөгөө

### 8. Хүний нөөц, удирдлага
- [ ] Бүтэц, орон тоо
- [ ] Ажлын горим (ээлж, улирал)
- [ ] Орон нутгаас ажиллах хүч

### 9. Эдийн засаг, санхүү
- [ ] Алтны үнэ (Монголбанк, LBMA)
- [ ] Роялти, Монголбанкинд тушаах нөхцөл
- [ ] Хөрөнгө оруулалтын зардал (CAPEX)
- [ ] Үйл ажиллагааны зардал (OPEX), нэгжийн өртөг
- [ ] Борлуулалтын орлого
- [ ] Татвар, роялти, төлбөр хураамж
- [ ] Мөнгөн урсгал, NPV, IRR, өртгөө нөхөх хугацаа
- [ ] Мэдрэмжийн шинжилгээ (үнэ, зардал, агуулга)

### 10. Эрсдэлийн шинжилгээ
- [ ] Агуулгын тархалт тогтворгүй
- [ ] Хаягдлын сангийн аюулгүй байдал
- [ ] Цианидын бохирдол
- [ ] Налуу нурах эрсдэл

### 11. Уурхайн хаалт
- [ ] Хаалтын төлөвлөгөө, зардал
- [ ] Хаалтын дараах хяналт

### Хавсралт
- [ ] Байршлын зураг, талбайн солбицол
- [ ] Геологийн зураг, зүсэлт
- [ ] Уурхайн ерөнхий төлөвлөгөө
- [ ] Технологийн схем
- [ ] Тооцооны хүснэгтүүд
- [ ] Албан бичиг, гэрээ

## Явц
