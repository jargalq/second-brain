## Онцлон судлах зүйлс
- Газрын доорх усны суурь хими, түвшин, урсгалын чиглэл
- Хөрсөн дэх хүнд металлын суурь агууламж
- Хүчиллэг ус үүсгэх чадвартай (сульфидтэй) чулуулгийн тархалт
- Хаягдлын сан, баяжуулах үйлдвэрийн талбайн газрын нөхцөл
- Ойролцоох худаг, булаг ашиглагчид

## Хэмжих гол үзүүлэлтүүд
- Ус: pH, CN, As, Hg, Pb, Cd, Cu, Zn, SO₄
- Хөрс: As, Hg, Pb, Cd, Cu, Zn
- Агаар: PM10, PM2.5
- Дуу чимээ, чичиргээ

## Үе шат
- [ ] Судалгааны төлөвлөгөө, сорьцлолтын цэгүүд тогтоосон
- [ ] Хээрийн судалгаа хийсэн (улирал: )
- [ ] Сорьц лабораторид өгсөн
- [ ] Лабораторийн дүн ирсэн
- [ ] Тайлан бэлэн болсон
- [ ] БОННҮ-д тусгасан

## Тайлангийн бүлгүүд

### 1. Ерөнхий мэдээлэл
- [ ] Судалгааны зорилго, хамрах хүрээ
- [ ] Нөлөөллийн бүсийн хил, талбайн хэмжээ
- [ ] Судалгааны арга зүй, хугацаа, улирал
- [ ] Судалгаанд оролцсон мэргэжилтнүүд

### 2. Байршил, засаг захиргаа
- [ ] Аймаг, сум, баг, тусгай зөвшөөрлийн талбай
- [ ] Ойролцоох суурин, зам, дэд бүтэц хүртэлх зай

### 3. Уур амьсгал
- [ ] Агаарын температур, хур тунадас (ойрын цаг уурын станц)
- [ ] Салхины зонхилох чиглэл, хурд

### 4. Агаарын чанар
- [ ] Суурь хэмжилт (тоос, хийн бохирдуулагч)
- [ ] Агаар бохирдуулах одоогийн эх үүсвэр

### 5. Дуу чимээ, чичиргээ
- [ ] Суурь хэмжилт, ойролцоох мэдрэмтгий цэгүүд

### 6. Газарзүй, ландшафт
- [ ] Гадаргын хэлбэр, өндөршил, налуу
- [ ] Ландшафтын төрөл, үзэмж

### 7. Геологи, гидрогеологи
- [ ] Геологийн тогтоц
- [ ] Газрын доорх усны үе давхарга, түвшин

### 8. Хөрс
- [ ] Хөрсний төрөл, үржил шимт давхаргын зузаан
- [ ] Хөрсний сорьцлолт, хүнд металлын агууламж
- [ ] Эвдрэл, элэгдэл

### 9. Гадаргын ус
- [ ] Гол, горхи, нуур, булаг (зай, урсац)
- [ ] Усны чанарын шинжилгээ
- [ ] Усны сан бүс, хамгаалалтын бүс

### 10. Газрын доорх ус
- [ ] Худаг, цооногийн бүртгэл, түвшин
- [ ] Усны чанарын шинжилгээ
- [ ] Усны нөөц, ашиглалт → [[Алтны үндсэн орд - Усны дүгнэлт (БОННҮ)]]

### 11. Ургамлан нөмрөг
- [ ] Зүйлийн бүрэлдэхүүн, бүрхэц, ургац
- [ ] Ховор, нэн ховор зүйл
- [ ] Ойн сан

### 12. Амьтны аймаг
- [ ] Хөхтөн, шувуу, хэвлээр явагч, загас
- [ ] Ховор, нэн ховор зүйл, нүүдлийн зам

### 13. Тусгай хамгаалалттай газар
- [ ] Улсын болон орон нутгийн хамгаалалттай газартай давхцал, зай

### 14. Нийгэм, эдийн засаг
- [ ] Хүн ам, өрх, малчид
- [ ] Бэлчээр, өвөлжөө хаваржаа, малын тоо
- [ ] Ус ашиглагчид, эрүүл мэндийн байдал

### 15. Түүх, соёлын өв
- [ ] Дурсгалт газар, булш хиргисүүр, тахилгат газар

### 16. Одоогийн эвдрэл, бохирдол
- [ ] Өмнөх уурхайн болон гар аргын олборлолтын ул мөр
- [ ] Зам, хог хаягдал, бусад эвдрэл

### 17. Дүгнэлт
- [ ] Мэдрэмтгий бүрэлдэхүүнүүд
- [ ] Хяналт-шинжилгээний цэгийн санал

### Хавсралт
- [ ] Сорьцлолтын цэгийн зураг
- [ ] Лабораторийн шинжилгээний дүн
- [ ] Гэрэл зураг
