## Онцлог анхаарах зүйлс
- CaF₂ агуулга, хортой хольц (SiO₂, CaCO₃, S, P)
- Хүдрийн биет: судал, линз
- Сортын ангилал

## Хайгуулын гол аргууд
- Суваг малталт
- Цооног
- Химийн шинжилгээ (CaF₂ ба хольц)
- Технологийн сорьц

## Үе шат
- [ ] Гүйцэтгэгч: Грийтвишн ХХК-тай гэрээ байгуулсан
- [ ] Хайгуулын ажлын төлөвлөгөө батлуулсан
- [ ] Хээрийн ажил дууссан
- [ ] Лабораторийн шинжилгээний дүн ирсэн
- [ ] Нөөц тооцсон
- [ ] Тайлан бэлэн болсон
- [ ] Мэргэжлийн зөвлөлөөр хэлэлцүүлсэн
- [ ] Нөөц улсын бүртгэлд бүртгэгдсэн

## Тайлангийн бүлгүүд

### 1. Удиртгал
- [ ] Ажлын зорилго, зорилт
- [ ] Тусгай зөвшөөрөл, талбайн солбицол
- [ ] Гүйцэтгэгч (Грийтвишн ХХК), хугацаа, гүйцэтгэсэн ажлын товч

### 2. Талбайн газарзүй, эдийн засгийн тойм
- [ ] Байршил, засаг захиргаа, зам харилцаа
- [ ] Гадаргын хэлбэр, уур амьсгал, гидрографи
- [ ] Хүн ам, дэд бүтэц, эрчим хүч, усан хангамж

### 3. Өмнө хийгдсэн судалгаа
- [ ] Геологийн зураглал, эрэл, хайгуулын түүх

### 4. Бүс нутгийн геологи
- [ ] Стратиграфи, магмын чулуулаг, тектоник

### 5. Ордын геологи
- [ ] Ордын тогтоц, хүдрийн (ашигт малтмалын) биет
- [ ] Эрдэс найрлага, бүтэц

### 6. Хайгуулын ажлын арга зүй, тоо хэмжээ
- [ ] Геологийн зураглал
- [ ] Геофизик, геохими (хэрэв хийсэн бол)
- [ ] Малталт (суваг, шурф)
- [ ] Цооног өрөмдлөг

### 7. Сорьцлолт, шинжилгээ, чанарын хяналт
- [ ] Сорьцлолтын арга, тоо
- [ ] Лаборатори, шинжилгээний арга
- [ ] Чанарын хяналт (QA/QC)

### 8. Ашигт малтмалын чанар, технологийн шинж
- [ ] Химийн найрлага, физик шинж
- [ ] Технологийн туршилтын дүн

### 9. Гидрогеологи, инженер-геологийн нөхцөл
- [ ] Газрын доорх ус, усны орц
- [ ] Чулуулгийн бат бэх, налуугийн тогтворжилт

### 10. Нөөцийн тооцоо
- [ ] Кондиц: CaF₂ доод агуулга, хольцын дээд хязгаар
- [ ] Сорт тус бүрээр нөөц
- [ ] Нөөц: хүдэр (т), CaF₂ (т)
- [ ] Нөөцийн ангилал
- [ ] Нөөцийн тооцооны хүснэгт, блокийн зураг

### 11. Байгаль орчин
- [ ] Хайгуулын ажлын нөлөө, нөхөн сэргээлт

### 12. Дүгнэлт, зөвлөмж
- [ ] Цаашдын хайгуул, ашиглалтын зөвлөмж

### Хавсралт
- [ ] Геологийн зураг, зүсэлт
- [ ] Цооног, малталтын баганан зураг
- [ ] Лабораторийн шинжилгээний дүн
- [ ] Нөөцийн блокийн зураг
- [ ] Тусгай зөвшөөрөл, албан бичиг
