## Онцлог анхаарах зүйлс
- Шороон давхаргын зузаан, хучаас чулуулгийн зузаан, хуулалтын коэффициент (м³/м³)
- Алтны агуулга (г/м³) ба ширхэглэлийн хэмжээ, сорьц (‰)
- Хөлдүү хөрс, мөнх цэвдэг байгаа эсэх
- Голын хөндий, горхины голдиролтой давхцал
- Ажлын улирал (ихэвчлэн 4–10 сар)

## ТЭЗҮ-ийн бүлгүүд

### 1. Ерөнхий мэдээлэл
- [ ] Төслийн зорилго, үндэслэл
- [ ] Тусгай зөвшөөрөл, талбайн солбицол, хэмжээ
- [ ] Засаг захиргаа, газарзүйн байршил, уур амьсгал
- [ ] Дэд бүтэц: зам, эрчим хүч, суурин газар хүртэлх зай
- [ ] Өмнө хийгдсэн ажлууд

### 2. Геологи, нөөц
- [ ] Хайгуулын үр дүн → [[Алтны шороон орд - Хайгуулын тайлан]]
- [ ] Шороон давхаргын тархалт, хэвтээ ба босоо зүсэлт
- [ ] Блокчлол, агуулгын хүрээ (cut-off)
- [ ] Нөөцийн тооцоо (элс м³, алт кг)
- [ ] Шлихийн сорьцлолт, баяжуулалтын технологийн сорьц
- [ ] Нөөцийн бүртгэл, ЭБМЗ-ийн дүгнэлт

### 3. Уул уурхайн ажил
- [ ] Ашиглалтын систем: хуулалт → элс олборлолт → угаалга → нөхөн сэргээлт
- [ ] Хөрс хуулалтын технологи (бульдозер, экскаватор)
- [ ] Элс тээвэрлэлт, угаах төхөөрөмж хүртэлх зай
- [ ] Уурхайн хил, блокуудын дараалал, жилийн бүтээмж (м³/жил)
- [ ] Хаягдал овоолго, үржил шимт хөрсний овоолгын байршил
- [ ] Тоног төхөөрөмжийн тооцоо, ээлжийн хуваарь
- [ ] Уурхайн ажлын календарь төлөвлөгөө

### 4. Баяжуулалт, боловсруулалт
- [ ] Гравитацийн баяжуулалт: угаах төхөөрөмж (скруббер, шлюз, отсадка, төвөөс зугтах баяжуулагч)
- [ ] Шлих баяжмалыг цэвэрлэх, алтыг хүлээлгэн өгөх журам
- [ ] Эргэлтийн усан хангамж, тунгаах сан
- [ ] Мөнгөн ус, химийн бодис хэрэглэхгүй байх шаардлага
- [ ] Металл авалтын хувь (%)

### 5. Дэд бүтэц, туслах байгууламж
- [ ] Цахилгаан хангамж
- [ ] Ус хангамж, ус зайлуулалт → [[Алтны шороон орд - Усны дүгнэлт (ТЭЗҮ)]]
- [ ] Зам, тээвэр
- [ ] Ажилчдын байр, засварын газар, агуулах
- [ ] Шатахуун хадгалах, түгээх

### 6. Байгаль орчин, нөхөн сэргээлт
- [ ] Сөрөг нөлөөлөл, бууруулах арга хэмжээ
- [ ] Техникийн ба биологийн нөхөн сэргээлт, зардал
- [ ] Нарийвчилсан үнэлгээ → [[Алтны шороон орд - БОННҮ]]

### 7. Хөдөлмөрийн аюулгүй байдал, эрүүл ахуй
- [ ] Аюултай хүчин зүйлс, эрсдэлийн үнэлгээ
- [ ] Галын аюулгүй байдал, осол, ослын үеийн төлөвлөгөө

### 8. Хүний нөөц, удирдлага
- [ ] Бүтэц, орон тоо
- [ ] Ажлын горим (ээлж, улирал)
- [ ] Орон нутгаас ажиллах хүч

### 9. Эдийн засаг, санхүү
- [ ] Алтны үнэ (Монголбанкны худалдан авалтын үнэ)
- [ ] Роялти, Монголбанкинд тушаах нөхцөл
- [ ] Хөрөнгө оруулалтын зардал (CAPEX)
- [ ] Үйл ажиллагааны зардал (OPEX), нэгжийн өртөг
- [ ] Борлуулалтын орлого
- [ ] Татвар, роялти, төлбөр хураамж
- [ ] Мөнгөн урсгал, NPV, IRR, өртгөө нөхөх хугацаа
- [ ] Мэдрэмжийн шинжилгээ (үнэ, зардал, агуулга)

### 10. Эрсдэлийн шинжилгээ
- [ ] Агуулгын хэлбэлзэл, нөөц баталгаажилт
- [ ] Үерийн аюул, голдирол өөрчлөгдөх
- [ ] Орон нутгийн иргэдийн эсэргүүцэл
- [ ] Гар аргын олборлогч нэвтрэх

### 11. Уурхайн хаалт
- [ ] Хаалтын төлөвлөгөө, зардал
- [ ] Хаалтын дараах хяналт

### Хавсралт
- [ ] Байршлын зураг, талбайн солбицол
- [ ] Геологийн зураг, зүсэлт
- [ ] Уурхайн ерөнхий төлөвлөгөө
- [ ] Технологийн схем
- [ ] Тооцооны хүснэгтүүд
- [ ] Албан бичиг, гэрээ

## Явц
- [ ] Гүйцэтгэгч: Грийтвишн ХХК-тай гэрээ байгуулсан
- [ ] Геологи, нөөцийн материал хүлээн авсан

- [ ] Уул уурхайн хэсэг бэлэн
