# Судалгааг «батлагдсан олдвор» аргаар гаргана

## For future agent

Mugi 2026-11-12-нд гадны artifact-ийн (хууль, татварын судалгаа) аргыг «reverse» хийж авахыг хүсээд «Арга, загвар»-ыг сонгов. Агуулгыг нь биш, арга, бүтцийг нь skill болгосон.

- **Хэн:** Mugi (сонголт), GTD сешн (skill бичсэн).
- **Юу:** хууль, татвар, ТЭЗҮ, БОННҮ судалгаанд 3 чиглэлийн хайлт → олдвор бүрийг тусдаа agent эхээс шалгах → зөвхөн батлагдсанаар шошготой нэгтгэх → «олдсонгүй», нээлттэй асуулт, сөрөг шалгалт.
- **Яагаад:** олдвор бүр эх сурвалжтай, зохиомол тоо, заалт орохгүй.
- **Буцааж болох уу:** тийм — skill-ийг устгах эсвэл засахад хангалттай.
