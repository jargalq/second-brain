# D:, C: дискийн давхардсан файлыг Recycle Bin руу шилжүүлэх

- **Хэн:** Мөнхжаргал зөвшөөрсөн ("Тийм, шилжүүл"), Claude гүйцэтгэсэн.
- **Шийдвэр:** Ижил нэр, ижил хэмжээтэй, SHA256-аар агуулга нь яг ижил файлаас эх хувийг нь үлдээж, давхардсан хувийг бүрмөсөн биш Recycle Bin руу шилжүүлэв.
  - D: 63 хавтас, 888 файл (3,845 МБ). C: 60 файл (76.8 МБ). Нийт 948 файл, ~3.9 ГБ.
  - Шилжүүлэхийн өмнө файл бүрийн SHA256-ийг дахин тооцож шалгасан, нэг ч файл алгасагдаагүй.
- **Хөндөөгүй:**
  - Vault-аас `file:///` холбоостой файлууд (холбоос эвдрээгүй).
  - `Great Vision project` доторх Micromine, Minex, Surpac, GIS-ийн ажлын өгөгдөл (~27 ГБ). Программууд төсөлдөө замаар нь холбодог.
  - `Softwares`, `ASUS Driver` (~11 ГБ), ArcGIS `.gdb` дотоод файлууд.
- **Яагаад:** Диск чөлөөлөх. Харин ажлын өгөгдөл устгавал төсөл нээгдэхгүй болох эрсдэлтэй тул зөвхөн нотлогдсон давхардлыг хөндсөн.
- **Буцааж болох эсэх:** Болно, Recycle Bin хоосолтол. Хоослох эсэхийг Мөнхжаргал өөрөө шийднэ.
- **Нээлттэй:** Үлдсэн ~38 ГБ давхардлыг төсөл тус бүрээр гараар шалгана.
