# Сур вэб апп (SaaS) байна: Next.js, Supabase, Vercel, програм дотор AI-гүй

## For future agent
Сур-ын технологи, байршуулалтыг өөрчлөхөөс өмнө үүнийг унш. Бүтэн spec: [[Сур - MVP дизайн ба бизнес төлөвлөгөө]].

- **Хэн:** Mugi (2026-11-05, «Арьс ширний компаниудад зориулсан програм» сешн; «Програм хаана ажиллах вэ?» асуултад «а», техникийн бүтцэд «зөв»).
- **Шийдвэр:**
  - Интернэтэд ажиллах вэб апп (SaaS); үйлдвэр юу ч суулгахгүй.
  - Next.js + Supabase (PostgreSQL, нэвтрэлт), Vercel дээр байршуулна.
  - Олон үйлдвэр нэг системд (multi-tenant), row-level security-ээр тусгаарлана; Холбоо зөвхөн нэгтгэсэн тоо харна.
  - Програм дотор AI огт байхгүй; AI-г зөвхөн код бичихэд ашиглана.
  - Excel импорт, экспорт SheetJS-ээр; интерфейс бүхэлдээ монголоор.
  - Supabase-ийн серверийг Азийн бүсэд (Сингапур эсвэл Токио).
- **Яагаад:** SaaS загвар ба Холбооны нэгдсэн тайланд хамгийн тохиромжтой; Грийтвишний сайт ч Vercel дээр тул нэг орчин.
- **Сул тал:** интернэт тасарвал ажиллахгүй.
