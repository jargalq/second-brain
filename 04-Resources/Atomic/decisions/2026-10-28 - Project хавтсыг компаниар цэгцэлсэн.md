# Project хавтсыг компаниар цэгцэлсэн

- **Хэн:** би (Claude хэрэгжүүлсэн)
- **Юу:** Хуучин `Project/` хавтсыг ашигт малтмалын төрлөөр (алт, жонш, барилгын чулуу …) бүтээсэн нь буруу байсан.
  - Төрөл бүрийн ТЭЗҮ, БОННҮ бүтцийг загвар болгож `_system/templates/ТЭЗҮ, БОННҮ загвар/` руу нэгтгэсэн → [[ТЭЗҮ, БОННҮ загвар]] *(2026-10-29: `04-Resources/` руу зөөсөн → [[2026-10-29 - ТЭЗҮ, БОННҮ загварыг Resources руу зөөсөн]])*
  - Бодит ажлыг компаниар нь `02-Projects/Ажил/<Компани>/` хавтсанд хийсэн. [[Баянгийн их ам]] → Амьдралын илч ХХК.
  - `Төслийн нэгтгэл.base`-ийн шүүлтүүрийг `02-Projects/Ажил` болгосон.
- **Яагаад:** Ажил компаниар (захиалагчаар) явагддаг. Загвар ба бодит ажил холилдохгүй байх ёстой.
- **Буцааж болох уу:** Тийм. Хавтсуудыг буцааж зөөхөд л болно. Тэмдэглэлийн нэр өөрчлөгдөөгүй тул wikilink эвдрэхгүй.
