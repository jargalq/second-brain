# Онгон хайрхан-1: баяжуулах үйлдвэрийг спираль, ширээний схемээр дахин сонгож, загвар v6-д тусгав

- **Хэн:** Мөнхжаргал баталсан («Тийм, v6 хий», 2026-11-06)
- **Шийдвэр:** 2021 оны хүчин чадал нь хүрэлцэхгүй байсан тоног төхөөрөмжийг 99.7 т/ц-д (зохиомжоор 114.6) дахин сонгов. Схем: шаталсан тэжээгч → хацарт PE-600×900 → стандарт ба богино толгойт конус (HP200 ангилал) → −10 мм → саваат тээрэм ×2 (−2 мм) → гидроциклон → спираль 29 → ширээ 18 → флотаци → өндөр эрчимт соронзон сепаратор, өтгөрүүлэгч Ø18 м. Үйлдвэрийн хөрөнгө оруулалт 25,502.2 сая ₮ (нөөцгүй). Үүнийг эдийн засгийн загварт `Оролт!PLANT26` нэрээр оруулав.
- **Яагаад:**
  - 2021 оны схемээр 153 ширээ шаардлагатай байсан. Спиралиар урьдчилан баяжуулахад ширээний тэжээл ≈8 дахин буурна.
  - Энэ схем 1990 оны хагас үйлдвэрийн туршилтын зарчимтай (гравитаци 2 шат, соронзон цэвэрлэгээ) нийцнэ. Спираль нь конус сепараторын орчин үеийн орлуулагч.
  - Вольфрамит шламждаг тул бөмбөлгөн тээрмийн оронд саваат тээрэм сонгосон.
- **Үр дагавар:**
  - CAPEX 63.7 → 68.4 тэрбум ₮. Суурь NPV 455.9 → 452.7 тэрбум ₮, IRR 166 → 157%, нөхөх хугацаа 1.58 → 1.61 жил. NPV = 0 үнэ ≈11,768 $/т.
  - Эрчим хүч 12.3 кВт.ц/т (3,954 ₮/т). Загварын таамаг 4,143 ₮/т байсан тул баяжуулалтын нэгж зардлыг өөрчлөөгүй.
  - Тоног төхөөрөмж, барилгын үнэ болон Бондын индекс (14) таамаг (±30%) тул үнийн санал, туршилтаар батална. 80%-ийн авалт нотлогдоогүй хэвээр.
- **Буцааж болох эсэх:** болно. `Оролт!PLANT26`-г өөрчилж (v5-ын утга `=CAPEX!F24*IMPF`), BEF-ийг дахин goal-seek хийнэ.
