# AutoCAD байхгүй PC дээр DWG-г ezdxf + PyMuPDF-ээр вектор PDF болгож болно

## For future agent
Энэ PC-д AutoCAD алга (ODA File Converter 27.10, ezdxf 1.4.5, PyMuPDF суусан; LibreOffice алга). 2026-11-06-нд Оюут-Овоогийн 10 хуудсыг ингэж гаргаж, хуудас бүрийг нүдээр шалгасан — штамп, лого, кирилл, hatch зөв. AutoCAD-ын хэвлэлттэй харьцуулаагүй (шугамын зузаан, фонт бага зэрэг ялгаатай байж болно).

## Арга
1. DWG → DXF: ODA File Converter (`ACAD2018 DXF`).
2. `ezdxf.addons.drawing` Frontend + `PyMuPdfBackend`, `Configuration(background_policy=WHITE, color_policy=COLOR)`.
3. Modelspace-д зурсан хуудсыг хүрээгээр нь (`Defpoints` эсвэл `0` давхаргын тэгш өнцөгт) `render_box`-оор тайрна; хуудасны хэмжээ = хүрээ × 1000 / масштаб (мм) → штампын масштаб жинхэнэ хэвээр.
4. Скрипт: scratchpad `topdf.py` (src, dst, JSON jobs: `{"box":[…],"scale":2000}` эсвэл `{"box":[…],"width":297}`).

## Урхи
- **Нэг backend = нэг хуудас.** `get_pdf_bytes`-ийг хоёр дахь удаа дуудахад хоосон хуудас гарна — хуудас бүрд Frontend-ийг дахин ажиллуул.
- **Далдлалттай MULTILEADER хар хайрцаг болно** (COLOR горимд цагаан арын өнгийг хар болгодог) — PDF-ийн хуулбарт тэдгээрийг `virtual_entities()`-ээр задлаад HATCH-ийг хая.
- **«м³»:** MTEXT-д `\S3^;` буруу харагдана; ТЭЗҮ-ийн хэлбэр `м\H0.7x;\S3^ ;` (зайтай) зөв. Шууд «³», «×», «–» тэмдэгт `c204` фонттой буруу гарна.
- Fit-to-page хуудас нь хүрээний харьцаанаас өөр бол хүрээний гаднах зүйл (хэмжээс) хуудсанд орно — хуудсыг хүрээний харьцаагаар үүсгэ.
- Оюут-Овоогийн хүрээ штампд «A1» гэсэн ч жинхэнэ хэмжээ нь A1 биш (838×698, 843×988, 746×907 мм).
