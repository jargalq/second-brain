# Figma-ийн нээлттэй дизайн файлд PDF шууд орохгүй, хуудас бүрийг SVG болгож буулгана

## For future agent
2026-11-05-нд Баруун нарангийн хөрөнгө оруулагчийн танилцуулгыг (15 х., HTML-ээс гаргасан PDF) Figma-д оруулах үед туршиж олсон баримт.

## Баримт
- Figma desktop нь нээлттэй дизайн файл руу PDF оруулахыг дэмждэггүй. «Place image» цонхоор оруулахад «import failed», файлыг буулгахад «PDF import is not supported» гэсэн алдаа гарна.
- Ажилласан арга:
  1. PyMuPDF-ийн `get_svg_image(text_as_path=0)` функцээр хуудас бүрийг SVG болгоно.
  2. Chrome-оос гаргасан PDF-д фонт Type3 болж хадгалагддаг. Тиймээс фонтын нэрийг Montserrat (≥18 px) эсвэл Inter болгож сольж, тод бичгийг үсгийн өргөнөөр тааж тогтооно.
  3. Үсэг бүрээр хуваагдсан текстийг мөр тутам нэгтгэнэ. Харин хоорондоо том зайтай хэсгийг, жишээ нь хүснэгтийн баганыг, нэгтгэхгүй.
- SVG файлуудыг Windows clipboard-д file-drop жагсаалт болгон хуулж, canvas дээр Ctrl+V дарахад BN_01…BN_15 frame болж орсон. Текст нь засах боломжтой давхарга болдог.
- XML буруу SVG-г (жишээ нь давхардсан attribute-тай) Figma ямар ч мэдэгдэлгүйгээр алгасдаг. Буулгахаасаа өмнө `xml.etree`-ээр шалгах хэрэгтэй.
- Mongolian гарын байрлалтай үед SendKeys-ийн `^a`, `^v` ажилладаггүй. Оронд нь `keybd_event`-ээр VK кодыг шууд илгээнэ.
- Скрипт: `mksvg.py` (сешний scratchpad, хадгалагдаагүй). Дахин хэрэгтэй бол `_system/skills/`-д хуулах.
