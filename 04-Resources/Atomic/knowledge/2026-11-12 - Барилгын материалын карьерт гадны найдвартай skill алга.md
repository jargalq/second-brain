# Барилгын материалын карьерт зориулсан найдвартай гадны skill, MCP алга; өөрийн эзлэхүүний горимыг хөгжүүлэх нь зөв

## For future agent
2026-11-12-ны судалгаагаар андезит, дайрга, элс хайрганы карьерыг эзлэхүүнээр төлөвлөдөг, итгэж болох гуравдагч талын Claude skill, plugin, MCP server олдсонгүй.
- **Seequent Evo MCP** арилжааны платформ шаарддаг ([GitHub](https://api.github.com/repos/SeequentEvo/evo-mcp), 2026-11-12).
- **Хүрээ оновчлогч сан** (PyMineFlow, MineFlow, MIT) агуулгагүй карьерт бараг юу ч нэмэхгүй. Ийм карьерын хүрээг нөөцийн полигон, ул, налуу, гэрээний хүчин чадал тогтоодог. Henley (1989) карьерт LG-ийн үр дүнг «good sub-optimal» гэж анхааруулсан.
- **Татгалзах:**
  - PyPI `pseudoflow`: арилжааны бус лицензтэй.
  - `jjsantos01/qgis_mcp`: лицензгүй, нэвтрэлтгүй socket-оор дурын код ажиллуулдаг.
  - `Codemod3/CAD-MCP`: 1 одтой, нэг өдрийн репо.
- **Ашиглаж болох:** permissive лицензтэй сан (ezdxf, trimesh, PyVista, shapely), хөрсний эзлэхүүнийг хөндлөнгөөс шалгах QGIS Volume Calculation Tool. `puran-water/autocad-mcp` (MIT) боловсорсон ч `execute_lisp`-ээр дурын код ажиллуулдаг. Одоогийн DXF→DWG урсгал ажиллаж байгаа тул хэрэггүй.

Нотолгоо: эзлэхүүний горимын прототип Зүүн нарангийн нөөцийг −1.3 %, уурхайг 749 565 м³ (батлагдсан 750 095), хугацааг 5 жил гэж гаргасан. Хананы налуу нэмээгүй тул хөрс −10.2 % зөрсөн.
