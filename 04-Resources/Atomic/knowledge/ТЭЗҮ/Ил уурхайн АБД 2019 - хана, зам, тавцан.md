# Ил уурхайн аюулгүй байдлын дүрэм 2019: хана, тавцан, зам

> ТЭЗҮ-ийн уурхайн хана, налуу зам зохиоход хэрэгтэй заалтууд. Текстийг legalinfo.mn-ээс 2026-11-02-нд уншиж товчлов. Хуулбарлаж иш татахаасаа өмнө эх заалттай тулгана.

| Заалт | Шаардлага |
|---|---|
| §30 | Түвшин бүрийн доголын ирмэгээс 2.0 м-ээс дотогш хүн, тоног төхөөрөмж орохыг хориглоно |
| §19 | Унах аюултай догол, мөргөцгийн ирмэг, нурал руу орох замыг далан, хаалтаар хаана эсвэл анхааруулах тэмдэг тавина. Шөнө гэрэлтүүлнэ. Зумф таглаа, хаалттай байна |
| §39а | Шууд утгуурт экскаватор, ачигчийн доголын өндөр ≤ утгалтын хамгийн их өндөр |
| §39б | **Урвуу утгуурт экскаваторын доголын өндөр ≤ утгалтын гүн** |
| §39е | Гар ажиллагаагаар: сул чулуулагт ≤ 3 м, цул чулуулагт ≤ 6 м |
| §40а | Экскаватор ажиллах доголын хажуугийн өнцөг ≤ 80°. Ажлын бус хажууг төслөөр тогтооно |
| §43 | Зам, байгууламжийг нурлын эсвэл доголын доод ирмэгээс ≥ 2.5 м зайд байрлуулна |
| §46 | **Аюулгүйн тавцан ≥ дээд доголын өндрийн 1/3.** Тээврийн тавцанг замын нөхцөлөөр тогтооно. Ажлын бус доголууд ерөнхий өнцөгт захирагдана. Тавцанг тоног төхөөрөмжөөр цэвэрлэх боломжтой байна |
| §47 | Хүн байнга явдаг тавцангийн ирмэгт хамгаалалтын хөмсөг, хашлага хийнэ |
| §57 | Өрмийн машин доголын дээд ирмэгээс ≥ 3 м зайд, нурлын бүсээс гадна ажиллана |
| §95 | Бульдозерийн овоолгын ирмэгт ≥ 3° хөндлөн налуутай байна. Далангийн өндөр ≥ хамгийн том өөрөө буулгагчийн дугуйн диаметрийн ½ |
| §233 | **Авто замын налуу ≤ 8–12 %** (техникийн баримт бичгийн дагуу). Тракторынх ≤ 15 % |
| §239 | **Нэг урсгалын замын зорчих хэсэг ≥ хамгийн том машины өргөн × 1.5.** Сөрөг урсгалтай байнгын замд тусгаарлах далан ≥ ½ дугуйн диаметр. Траншейн түр замд машины хажуугаар ≥ 1.5 м зай үлдээнэ. Нарийн замд 150 м тутамд зөрөх зай гаргана |
| §240 | **Догол, овоолго дээрх замын хамгаалах далан (хашлага) ≥ ½ дугуйн диаметр** |
| §241 | Цул, тогтвортой чулуулагт далангийн захаас доголын ирмэг хүртэл ≥ 1 м |
| §251 | Ачих, буулгах талбайн налуу ≤ 1 %. Ухрах хэсэгт далан ≥ ½ дугуйн диаметр |
| §497 | Ажлын талбайн (дэд догол) өргөн ≥ 3 м. Явган хүний зам ≥ 1 м |

## Жишээ хэрэглээ: Зүүн наран (v5, 2026-11-02)
- Шатны өндөр 5 м, R380LC-9-ийн утгалтын гүн ≈ 7.4 м ⚠️ → §39б хангана.
- Ажлын налуу 60°, хөрсний налуу 45° → §40а хангана.
- Тавцан 2.8 м ≥ 5/3 = 1.67 м → §46 хангана. Ерөнхий налуу 40° болно.
- Налуу зам 8 % → §233. Зорчих хэсэг 7.5 м ≥ 3.75 м (HOWO-ийн өргөн 2.5 м ⚠️) → §239.
- Замын далан 0.6 м ≥ 0.56 м (12.00R20 дугуй ⚠️) → §240.
