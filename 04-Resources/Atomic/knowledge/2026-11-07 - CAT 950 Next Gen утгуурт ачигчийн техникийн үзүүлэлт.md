# CAT 950 (Next Gen) утгуурт ачигчийн техникийн үзүүлэлт

## For future agent
Онгон хайрхан-1-ийн ТЭЗҮ-ийн бүрэн текстийн Хүснэгт 23ж-д (v4, 2026-11-07) оруулсан утгууд. Интернетээс авсан тул нийлүүлэх машины паспортоор тулгана. 950 GC бол өөр (хямд) загвар, түүний тоог хольж болохгүй.

| Үзүүлэлт | CAT 950 (Next Gen) |
|---|---|
| Хөдөлгүүр | Cat C7.1, 186 кВт (253 м.х) |
| Масс | 18,076 кг (АНУ-ын тохиргоо 19,260 кг) |
| Утгуурын багтаамж | 2.5–9.9 м³ (сонгох утгуураас хамаарна) |
| Гидравлик мөчлөг | 9.8 сек |
| Шарнирын хамгийн их өндөр | 4,009 мм (стандарт өргөлттэй) |
| Урт / өргөн / өндөр | 6,797 мм (утгуургүй) / 2,824 мм / 3,456 мм |

- **Олдоогүй:** 45°-аар ачилт хийх өндөр, арын эргэлтийн радиус. Хүснэгтэд «тодруулах» гэж тэмдэглэсэн. `TBD: нийлүүлэгчийн паспортоор`.
- **Эх сурвалж:** Borusan Cat (Казахстан), Cat 950 (14C); Cat-ийн хэвлэлийн мэдээ. Хайсан огноо 2026-11-07. `TBD: URL — сешний хураангуйд тасарсан`.
- Хүснэгт 23-ын ачигчийн мөрөнд «186 кВт, ≈238 т/ц» гэж нэмсэн. Хуучин машин авах тул хөдөлгүүрийн эко стандарт, мото цагийг шалгахыг хүснэгтийн тайлбарт тэмдэглэсэн.
