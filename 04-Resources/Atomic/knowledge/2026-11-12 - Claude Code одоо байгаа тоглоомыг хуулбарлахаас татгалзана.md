# Claude Code 2026 оны 10-р сараас эхлэн одоо байгаа тодорхой тоглоомыг хуулбарлахаас татгалзана

## For future agent
Anthropic компани 2026-10-27-ны орчим Claude Code-ийн system prompt-д хоёр өгүүлбэр нэмжээ. Үүгээр анхны тоглоом, нэг төрлийн тоглоом, хэрэглэгчийн өөрийн дизайнаар хийсэн тоглоомыг бүтээхийг зөвшөөрч, нэрийг нь сольсон ч гэсэн **тодорхой нэг одоо байгаа тоглоомыг дахин бүтээхийг** хориглосон. Шалтгаан нь оюуны өмч зөрчихийг хориглосон хэрэглээний бодлого юм. Үүнийг Anthropic-ийн ажилтан Addy Osmani тайлбарласан ([Game Developer, 2026-10-30](https://www.gamedeveloper.com/programming/anthropic-appears-to-have-ordered-ai-tool-claude-to-stop-remaking-video-games)).

Нөхцөл байдал: AI-аар тоглоомын binary-г задалж (decompile) Diablo II, GTA 2 зэргийг дахин бүтээх нь трэнд болсон ([PCWorld, 2026-11-02](https://www.pcworld.com/article/3274819/)).

Хориг ерөнхий reverse engineering-д хүрч байгаа эсэх нь **баталгаажаагүй**, эх сурвалжууд зөрж байна.
