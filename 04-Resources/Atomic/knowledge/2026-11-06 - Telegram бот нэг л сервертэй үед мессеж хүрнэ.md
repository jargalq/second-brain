# Telegram бот нэг л сервертэй үед мессеж Claude-д хүрнэ

## For future agent

2026-11-05-нд @aiqmunkhjargal_bot-ыг CLI сешнтэй холбоход туршилтын мессеж ирээгүй. Шалгахад процессын жагсаалтаас шалтгааныг олов (таамаг биш).

## Гол санаа

- Telegram-ын Bot API нэг ботын мессежийг **нэг л сонсогч** (poller) авдаг. Хэд хэдэн сервер зэрэг сонсвол мессежийг санамсаргүй нэг нь булааж авна.
- Claude desktop апп-ын сешн бүр Telegram plugin-ий өөрийн серверийг (`bun.exe`, `Claude/rpm/.../plugin_01VdXP3hUf4WXSKxP9zJ7b26`) асаадаг. Desktop сешн мессеж хүлээн авч чаддаггүй тул булаасан мессеж гээгдэнэ.
- Мессеж хүлээн авах ёстой нь зөвхөн CLI сешн: `claude.exe --channels plugin:telegram@claude-plugins-official`.
- **Шийдэл:** Telegram ашиглах үед desktop сешнүүдийн Telegram серверийг хаах (эсвэл тэр сешнүүдийг хаах). Шинэ desktop сешн нээх бүрд сервер дахин асна.
- Өөр сешний процессыг Claude auto mode-оор зогсоох нь хориглогддог — Mugi өөрөө PowerShell-ээр хаана.
