# ГМТ - ТЭЗҮ хүлээн авах заавар

## For future agent
ngs.gov.mn-ээс 2026-11-12-нд татсан 21 хуудас. Бүтэц нь [[ГМТ - Хайгуулын ажлын үр дүнгийн тайлан хүлээн авах заавар]]-тай ижил (нүүр бичилт, батлагдсан нүүр, гарчиг, хэлбэр, хавсралт зураг, цахим хувь); ялгаа нь хээрийн баримт, чулуун дээжгүй. Бүтэн текст эх файлд.

## Бүрдэл
1. Бичвэр (ерөнхий мэдээлэл, геологи, олборлолт, баяжуулалт, дэд бүтэц, ХАБЭА, нийгэм, эрсдэл, байгаль орчин, хэрэгжүүлэх төлөвлөгөө, эдийн засаг, санхүү).
2. Хавсралт баримт (ЭБМЗ-ийн дүгнэлт, батлах тушаал, шинжээчийн дүгнэлт, хариу).
3. Хавсралт зураг. 4. Цахим хувь.
- Баримтын мэдээллийн хуудсанд «ТЭЗҮ-г хянаж баталсан төрийн захиргааны төв байгууллагын тушаал, шийдвэр» гэх мэт 17 талбар бөглөнө.

## Бидэнд юунд хэрэгтэй
ТЭЗҮ-г ЭБМЗ-өөр батлуулсны дараа CD, хэвлэмэл хувийг архивт өгөхөд → [[tezu]] skill-ийн CD хүргэлтийн алхамтай тулгах.
