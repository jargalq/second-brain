# Мэргэшсэн мэргэжилтэн, шинжээчийн эрх олгох журам (2020, А-341)

## For future agent
legalinfo.mn-д тушаал нь бүртгэлтэй, хүчинтэй (2026-11-12). Журмын хавсралт нь зөвхөн «Татах» файлаар байдаг тул **бүтэн текстийг татаагүй** — хэрэгтэй үед legalinfo.mn-ийн «Хавсралт» табаас (id 16123489777561) татна.

## Гол агуулга (тушаалаас)
- «Геологи, уул уурхайн салбарын мэргэшсэн мэргэжилтэн, шинжээчийн эрх олгох асуудлыг мэргэжлийн төрийн бус байгууллагаар гүйцэтгүүлэх журам»-ыг баталсан (Ашигт малтмалын тухай хуулийн 10.1.16).
- Уул уурхайн сайдын 2015 оны 81-р тушаалыг хүчингүй болгосон.

## Бидэнд юунд хэрэгтэй
Нөөцийн тайлан, ТЭЗҮ-д гарын үсэг зурах мэргэшсэн мэргэжилтэн, ЭБМЗ-ийн шинжээчийн эрхийн үндэс. MRC кодын Competent Person-ийн шаардлагатай холбогдоно → [[MRC Code 2014 - Монголын нөөц тайлагнах код]].
