# MRC Code 2014 — Монголын нөөц тайлагнах код

## For future agent
CIM (Канад)-ийн CRIRSCO-ийн кодуудын хуудаснаас 2026-11-12-нд татсан англи хувилбар, 40 хуудас. Монгол хувилбар олдоогүй. Бүтэн текст эх файлд.

## Юу вэ
- Хайгуулын үр дүн, нөөц, баялгийг **олон нийтэд** (хөрөнгийн бирж, хөрөнгө оруулагч) тайлагнах доод шаардлага. CRIRSCO загварт тулгуурласан, JORC, NI 43-101-тэй дүйцэнэ.
- Улсын ангилал ([[Ашигт малтмалын баялаг, ордын нөөцийн ангилал, заавар (2015, №203)|2015, №203]]: A, B, C, P1–P3) ба олон улсын ангиллын (Measured, Indicated, Inferred; Proved, Probable) хоорондын дүйцлийг харгалзсан.
- Мэргэшсэн мэргэжилтэн (Competent Person) тайланд хариуцлага хүлээнэ → [[Мэргэшсэн мэргэжилтэн, шинжээчийн эрх олгох журам (2020, А-341)]].
- Хөрөнгийн биржийн журам MRC, JORC, NI 43-101, SAMREC-ийн аль нэгээр тайлагнахыг зөвшөөрдөг (mse.mn).

## Бидэнд юунд хэрэгтэй
Захиалагч хөрөнгө оруулагч, биржид нөөцөө танилцуулах, эсвэл гадаад түнш JORC тайлан шаардах үед улсын зэрэглэлийг олон улсын ангилалд хөрвүүлэх үндэс.
