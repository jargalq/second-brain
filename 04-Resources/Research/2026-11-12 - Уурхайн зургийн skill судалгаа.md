## Товч дүгнэлт

1. **Уул уурхайн зурагт зориулсан Claude skill олдсонгүй.** anthropics/skills (19 skill), claude-plugins-official (56 plugin), awesome-claude-skills-д CAD, GIS, уурхайн skill алга. Тэсэлгээний паспорт, штамп, уулын ажлын төлөвлөгөөний skill ч олдсонгүй. Энэ талбарт Mugi-ийн `zurag-uurhai` + `dairga` гадныхаас өмнө явж байна.
2. **Уурхайн программын MCP маш шинэ, бага.** Seequent Evo MCP (албан ёсны, эхний шат), Vulcan MCP (0 од), Deswik MCP (0 од, лицензгүй) л байна. **Surpac, Datamine, Micromine, Leapfrog Geo-д MCP олдсонгүй** — харин Mugi-ийн компьютер дээр GEOVIA Surpac 6.6.2 суусан байна.
3. **Хамгийн хэрэгтэй нь AutoCAD MCP ба ezdxf.** AutoCAD MCP 5+ төсөл байгаа; хамгийн идэвхтэй нь `autocad-mcp-pro` (COM, бүтэн AutoCAD) ба `puran-water/autocad-mcp` (AutoCAD LT). Mugi-ийн компьютер дээр AutoCAD 2024 бий.
4. **GIS MCP боловсорсон:** QGIS MCP (1 152 од), gis-mcp (205 од), GDAL MCP. Координат хувиргалт, ТЗ-ийн хил, shapefile-д хэрэг болно.
5. **Аюулгүй байдлын гол эрсдэл:** ихэнх CAD/GIS MCP «дурын код ажиллуулах» хэрэгсэлтэй (AutoLISP, Python `exec`). Prompt injection-оор (жишээ нь DWG доторх бичвэрээр) компьютер дээр код ажиллах боломж үүснэ.

## Шилдэг 3 санал

1. **ezdxf — `zurag-uurhai`-ийн дотор (MCP биш, номын сан).** Шалтгаан: MIT, сард 4.9 сая татан, 2026-10-нд шинэчлэгдсэн, сүлжээнд гардаггүй. Одоогийн `zn_dxfw` гар бичигчийг hatch, хэмжээс, блок, layout-тай болгож, DWG-д group-тэй гаргах ажлыг тогтвортой болгоно. Mugi-ийн python → SVG/PDF урсгалд шууд нийцнэ. *Анхаар:* skill-ийг өөрчлөхөөс өмнө Mugi-ийн зөвшөөрөл, хуулбар дээр тест, `_trash` нөөц ([[2026-11-12 - Skill-ийг эвдэхгүй, зөвхөн сайжруулна]]).
2. **autocad-mcp-pro — AutoCAD 2024-ийг шууд удирдах.** Шалтгаан: бүтэн AutoCAD-ыг COM-оор дэмждэг цорын ганц идэвхтэй, олон хэрэглэгчтэй төсөл; хамгаалалтын модуль (`security_lisp.py`, `policy.py`) бий. DWG нээж шалгах, давхарга цэгцлэх, PDF plot хийх давтагдсан ажлыг хурдасгана. *Анхаар:* хэрэгсэл 257, `send_command` байгаа тул тусдаа venv-д, DWG-ийн **хуулбар** дээр, дурын команд/LISP-ийг хаасан тохиргоотой туршина. Итгэл дунд.
3. **gis-mcp — координат, ТЗ-ийн хил.** Шалтгаан: MIT, GUI-гүй, python-оор ажилладаг, grep-ээр дурын код ажиллуулах хэрэгсэл олдсонгүй. ТЗ-ийн булангийн цэгийг WGS84 ↔ UTM хувиргах, талбай тооцох, shapefile-аас хил авах ажилд хэрэгтэй. Хувийн өгөгдөл локалд үлдэнэ.

> **Санаа (олдвор биш):** Surpac 6.6.2 суусан, гэвч Surpac MCP дэлхийд алга. Surpac TCL макро руу бичих жижиг MCP эсвэл skill-ийг өөрсдөө хийх нь ирээдүйн давуу тал болж магадгүй — **таамаг**, судлах шаардлагатай.
